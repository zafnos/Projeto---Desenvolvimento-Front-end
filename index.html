      LOCALIZA UNIPÊ

      Sobre o projeto

      O Localiza Unipê é um mapa interativo do campus, criado para ajudar estudantes e visitantes a encontrar blocos, setores e serviços da instituição.

      Como foi feito

      O projeto foi desenvolvido como uma aplicação web front-end. Os dados e a geometria do campus foram organizados para criar um mapa ilustrado e interativo, com busca, informações dos locais e controles de visualização.

      Tecnologias utilizadas

      HTML para a estrutura, CSS para a aparência e JavaScript para as interações. O mapa é desenhado em SVG, e o Git e o GitHub são usados no controle de versão do projeto.
